# legal-nz

Legal knowledge base and document management system for New Zealand law.

## Quality Framework

This project operates under the **Antigravity Swarm** with a dedicated **Quality_Validator** role ensuring:

- **Document Standards**: Compliance with NZ legal document formatting and citation standards
- **Code Quality**: Automated linting, type checking, and testing
- **Content Validation**: Verification of legal references, citations, and terminology
- **Data Integrity**: Validation of structured legal data and metadata

See [QUALITY_STANDARDS.md](QUALITY_STANDARDS.md) for the complete quality framework.
