# Project Workflow

1. Work on a scoped branch linked to a Conductor track and GitHub issue.
2. Preserve existing behavior and repository-specific validation.
3. Record authoritative evidence for external registry actions.
4. Keep externally gated work open until independently observable.
5. Accept production inputs only as versioned, checksummed `fyi-archive`
   packages with source and takedown revisions; do not scrape source sites.
6. Validate and mine the package before separately publishing the derived
   event-log dataset and bounded static dashboard assets.
