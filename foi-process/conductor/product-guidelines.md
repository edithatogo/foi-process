# Product Guidelines

- Prefer auditable, deterministic, reproducible outputs over opaque automation.
- Keep bounded, fixture, representative-live, and full-corpus evidence visibly distinct.
- Fail closed when provenance, privacy, rights, removal, or completeness evidence is absent.
- Use aggregate process metrics for public dashboards and avoid exposing unnecessary source text.
- Preserve source-specific rights and takedown controls independently of the code licence.
- Record external publication state from hosted evidence rather than repository intent.
