# Technology Stack

- Rust 1.88+ for contracts, replay, adapters, OCEL projection, and tests.
- Python 3.13 for bounded data packaging, validation, governance checks, and publication helpers.
- TypeScript/React/Vite for the static dashboard in `space/`.
- JSONL, JSON, and YAML for portable event-log, manifest, schema, and governance artefacts.
- GitHub Actions for reproducible validation and no-cost GitHub Pages/Hugging Face publication workflows.
- Hugging Face Hub and Zenodo/DataCite for externally deposited bounded artefacts.
