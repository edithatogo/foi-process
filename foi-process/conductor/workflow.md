# Workflow

1. Read the relevant track specification and plan before editing.
2. Make the smallest repository-scoped change that satisfies the plan.
3. Add or update focused tests and deterministic evidence.
4. Run formatting, lint, unit, contract, and relevant publication/governance checks.
5. Preserve unrelated dirty worktree changes.
6. Commit changes in reviewable units and reconcile the track plan with the actual commit.
7. Treat external publication, source rights, privacy, removal, and human governance as explicit gates.
