# Funding / subsidy work packages

These are evidence-oriented scopes suitable for grant, fellowship, civic-tech, or research-infrastructure applications. They are not claims of eligibility for any current programme.

## WP1 — Open FOI process-data infrastructure

Deliverables: reproducible FYI archive-to-OCEL pipeline, public schemas, Rust4PM contributions, benchmark report, signed dataset release, and documentation. Evidence: full-corpus throughput, reproducibility hashes, external consumer, upstream PRs.

## WP2 — Privacy-preserving document intelligence

Deliverables: selective OCR in `fe-reader`, Māori-aware semantic extraction in `nlp-policy-nz`, evidence geometry, human review workflow, and public/restricted indexes. Evidence: annotated evaluation set, OCR/NLP metrics, privacy regression tests, model cards.

## WP3 — Explainable OIA conformance

Deliverables: FOI-O profiles, RuleSpec NZ deadline rules, Axiom traces, human-certified fixture set, and dashboard explanations. Evidence: trace reproducibility, expert-reviewed gold cases, documented non-automation boundary.

## WP4 — Public-sector process digital twin

Deliverables: Kairos synthetic OCEL generator, authority queue/backlog scenarios, concept-drift and late-event benchmark suite, public demo data. Evidence: deterministic simulations, scenario validation, performance and sensitivity analyses.

## WP5 — Public interactive corpus explorer

Deliverables: Propel FOI profile, Hugging Face Static Space, accessible process maps, variants, timelines, evidence links, and privacy-safe search. Evidence: usability/accessibility testing, load benchmarks, deployment reproducibility.
