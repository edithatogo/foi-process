# Contributing

Keep changes scoped, reproducible, and evidence-backed. Preserve unrelated
worktree changes and keep source-derived rights separate from the Apache-2.0
code licence.

Before opening a pull request, run the narrowest relevant checks and report any
environmental limitation. Changes affecting publication, privacy, rights,
removal, credentials, or workflows must retain fail-closed behaviour.

This repository is maintained by one owner. Automated CI checks are the merge
gate; no mandatory human approval or CODEOWNERS team is required.
