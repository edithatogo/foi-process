# Event-log registry readiness

The bounded public-derived event-log release is externally preserved and
discoverable. This evidence applies only to the reviewed bounded release and
must not be interpreted as full-corpus coverage.

## Authoritative evidence

- Zenodo record: <https://zenodo.org/records/21660296>
- DataCite DOI: <https://doi.org/10.5281/zenodo.21660296>
- Hugging Face dataset: <https://huggingface.co/datasets/edithatogo/foi-process-event-logs>
- Verified Hugging Face revision: `be5337073cd4a2868e1ac812087b9d6d962f2570`
- Croissant metadata: <https://huggingface.co/api/datasets/edithatogo/foi-process-event-logs/croissant>

The Zenodo record contains the bounded event log, attachment inventory,
checksums, provenance, and DataCite metadata. Source-document rights remain
separate from the repository's Apache-2.0 code license. The Hugging Face
builder therefore retains `license: other` for source-derived data.

## Deferred scope

Issue [#63](https://github.com/edithatogo/foi-process/issues/63) tracks a future
full-corpus registry expansion. Any such release requires its own immutable
archive revision, takedown revision, completeness evidence, privacy and rights
decision, checksums, registry metadata, and hosted verification. The bounded
DOI and dataset revision do not satisfy those gates.
