# Source rights and licensing

The repository's **code and schemas** are licensed Apache-2.0. That licence does not apply to
FOI source records, attachments, WARC/WACZ captures, OCR, embeddings, or source-derived documents
unless a separate rights record explicitly says so.

Every source-derived artefact must carry or link to:

- source owner and canonical URL;
- source-stated licence or reuse basis;
- attribution text and required notice;
- permitted transformations and redistribution scope;
- retention and takedown conditions;
- review date and responsible owner.

The synthetic fixture dataset is deliberately labelled `other` in Hub metadata while production
source rights remain pending. Do not relabel it Apache-2.0 merely because the generating code is
Apache-2.0.
